# 🚀 Instalación Farm Horses Game

## Paso 1: Clonar el repositorio

```bash
git clone https://github.com/cheoportu1960-glitch/Jose.git
cd Jose
```

## Paso 2: Instalar dependencias

```bash
npm install
```

## Paso 3: Ejecutar en desarrollo

```bash
npm run dev
```

La webapp estará en: **http://localhost:5173**

---

## 📋 Controles

**Desktop:**
- **WASD** o **Flechas** = Mover
- **E** = Entrar en zona

**Móvil:**
- **Joystick en pantalla** = Mover
- **Tap en zona** = Entrar
